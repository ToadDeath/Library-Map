Each entry is a public library system, whether it is organized as a library district, city or town library, county library, or joint system. A district is one type of jurisdiction, not a separate kind of library. The map marker represents the system, not every branch. Shaded areas show district boundaries only where matching boundary data is available.

    How the map works

    Library system marker: identifies a public library organization. One system may operate several branches.

    Shaded district area: shows the legal service area of a library district where boundary data is available. Not every library system is a district, and not every district boundary is currently mapped.

    County outline: geographic reference only. County lines do not determine library-card eligibility.

    Borrowing around Colorado: many libraries participate in Colorado Libraries Collaborate, a reciprocal borrowing program. It is not one statewide card, and each library sets its own rules.
